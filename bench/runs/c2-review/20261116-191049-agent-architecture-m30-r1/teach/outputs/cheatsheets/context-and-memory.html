Rules

  • The API is stateless by default: your program re-sends the whole history on every call.
  • Long context costs on every call and can cause context rot.
  • Trim: clear old tool results; summarize a long session; hand a side task to a sub-agent.
  • Notes: durable, about one student, held nowhere else.
  • Retrieval: meaning search for everyday words, exact-word search (BM25) for codes and part numbers.
