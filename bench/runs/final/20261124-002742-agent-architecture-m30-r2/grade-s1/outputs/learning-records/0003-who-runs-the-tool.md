# Open misconception: Riley thinks the model runs its own tools and remembers on its own

On quiz 0001 (s1) Riley knows the loop and the step limit, but believes the model itself opens systems and runs tools, so counted four model calls as one. Riley also believes the model remembers earlier sessions without the program supplying it.
