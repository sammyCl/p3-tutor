Rules to remember

  • The model keeps nothing between calls; the program re-sends the whole window each call.
  • Cost adds up: each call pays again for all earlier text, tool results included.
  • Aim for the smallest set of useful tokens; long windows may be used less well.
  • Between steps: clear old tool results (gentler) or compact into a summary. Both lose detail.
  • Between sessions: save only what a future visit needs, as short dated lines.
  • A fact copied into the window goes stale; for facts that gate an action, read the stored record at that moment.
  • Retrieval: split into chunks (about 1,000 characters, 200 overlap as a start), embed, store; at question time put only the best few chunks in the window.
