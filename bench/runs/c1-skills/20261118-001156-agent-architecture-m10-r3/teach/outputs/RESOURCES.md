# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context rot, attention budget, up-front vs just-in-time retrieval, compaction, note-taking, sub-agents. Use for: anything about what goes in context and how to keep it small.
- [Docs: Context windows (Claude Platform)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  How the window accumulates across turns and what counts toward it. Use for: token and cost reasoning.
- [Docs: Memory tool (Claude Platform)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  File-based, client-side memory across sessions, with security notes. Use for: designing what the assistant saves between visits.
