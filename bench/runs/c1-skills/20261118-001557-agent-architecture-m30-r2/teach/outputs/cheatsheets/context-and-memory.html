Context and memory in an agent

From lesson 1. Sources: Anthropic, Claude docs, Contextual Retrieval.

Terms

  • Context window: all the text the model can use on one call, including its reply.
  • Token: a word or part of a word; the unit of size and cost.
  • Context rot: recall gets worse as the context grows.
  • Compaction: summarize a long run and continue in a fresh window.
  • Memory: information stored outside the window and loaded back on purpose.
  • Retrieval (RAG): fetch relevant chunks and put only those in context.
  • Chunk / embedding / BM25: a small piece of a document / numbers capturing its meaning / exact-word search.

Where does a fact belong?

FactPut it
Needed on every step (rules, tool list)In context, always
Short and needed this visit (training status)Saved record, loaded at the start
Large and fixed (manuals)Retrieved on demand, cleared after use
Result of a tool, no longer neededCleared or summarized
Needed next visit and not rebuildableSaved by your program at the end

Rules of thumb

  • The model remembers nothing between calls; your program re-sends or reloads.
  • Anything left in history is paid for again on every later step.
  • Trim what can be fetched again before what cannot.
  • Keep tool results short.
  • Exact terms (error codes) need keyword matching, not only meaning-based search.
