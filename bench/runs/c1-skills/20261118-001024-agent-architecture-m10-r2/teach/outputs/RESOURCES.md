# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Defines context, context rot, just-in-time retrieval, compaction and structured note-taking. Use for: what to keep in context, what to retrieve on demand, what to write to notes.
- [Docs: "Context windows" (Claude Platform docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Official description of what counts toward the window, how turns accumulate, and what happens at the limit. Use for: how the context window works in a real API call, and how it relates to cost.
