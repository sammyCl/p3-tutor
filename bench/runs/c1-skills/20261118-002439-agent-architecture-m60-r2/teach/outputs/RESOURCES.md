# Agent Architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context rot, attention budget, compaction, structured note-taking, just-in-time retrieval, sub-agents. Use for: what to keep in context and why.
- [Docs: Context windows (Claude API)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, how turns accumulate, window sizes, trimming options. Use for: how the window fills and what it costs.
- [Docs: Memory tool (Claude API)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Client-side file memory across sessions, security notes, multi-session pattern. Use for: saving notes between sessions.
- [Article: "Introducing Contextual Retrieval" (Anthropic Engineering)](https://www.anthropic.com/engineering/contextual-retrieval)
  Chunking, embeddings, BM25, the 200,000-token "skip RAG" rule, retrieval failure rates. Use for: finding the right page in a long manual.
