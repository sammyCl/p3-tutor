Context and memory in an agent

From Lesson 1.

Terms

TermMeaning
Context windowAll the text the model can read in one call, including its own reply.
TokenA small chunk of text; windows, cost and limits are counted in tokens.
Context rotAccuracy and recall fall as the window fills.
Context engineeringChoosing what goes into the window at each step.
CompactionSummarize the conversation and continue in a fresh window.
MemoryInformation stored outside the window and read back in through a tool.
Just-in-time retrievalKeep identifiers; load content only when a step needs it.

Where information lives

InformationLives inReaches the window by
Rules, tool descriptionsContextSent every call
This request's steps and resultsMessage list (your program)Resent every step
Facts about a studentSaved notesRead at session start
ManualsSearchable storageSearch, then read one section

Checks before adding to context

  • Will this be re-read on every later step? Is it worth that cost?
  • Is only the relevant part included?
  • Must it survive the session? Then save it as a note.
