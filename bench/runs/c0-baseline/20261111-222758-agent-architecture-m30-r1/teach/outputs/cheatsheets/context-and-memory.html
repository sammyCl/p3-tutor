Context and memory in an agent

From lesson 1.

Rules

  • The model sees only its context: system prompt, tool definitions, messages, tool results.
  • Every call resends the whole history, so total input = sum of each call's input; a result is paid for again on every later call.
  • Nothing survives a session unless the program stores it and reads it back.
  • The model sees only the passages a search returns.

Token arithmetic

Input of call n = input of call n-1 + the model's request + the tool result. Total = add all calls.

Long runs

Clear old tool results, then compact (summarise), then sub-agents. Keep tool results small first.
