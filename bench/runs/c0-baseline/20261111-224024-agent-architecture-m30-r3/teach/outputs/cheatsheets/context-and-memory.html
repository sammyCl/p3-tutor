Rules of thumb

  • The model keeps nothing between calls; the program resends the history.
  • Input tokens over a run = sum of the whole context at each call.
  • Bigger window is not a reason to put everything in: cost and recall both suffer (context rot).
  • Trim: clear used tool results, then compact if the history is still long.
  • Save facts, not transcripts.
