# Agent architecture Resources

## Knowledge

- [Effective context engineering for AI agents (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Attention budget, context rot, just-in-time retrieval, compaction, note-taking, sub-agents. Use for: anything about what goes in the context and how to keep it small.
- [Claude docs: Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Official description of what fills the window, context rot, compaction and context editing. Use for: precise facts on how the window works.
- [Introducing Contextual Retrieval (Anthropic)](https://anthropic.com/news/contextual-retrieval)
  RAG basics, chunking, embeddings versus BM25, and measured retrieval failure rates. Use for: designing manual search.
- [Claude docs: Memory tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  File-based memory executed by your own code. Use for: saving notes between sessions.
