Context and memory in an agent

From lesson 1.

Terms

  • Token: a chunk of text; limits and prices are counted in tokens.
  • Context window: all the text the model can use for one call, including its reply.
  • Context rot: recall and accuracy degrade as the context grows.
  • Session: one conversation or task; its context is gone when it ends.
  • Retrieval: fetching outside information into the context.
  • Notes (memory): facts the agent writes outside the context to read later.
  • Compaction: summarize a nearly full conversation and continue from the summary.

Cost rule

Each call re-reads the whole context. Input at call n = base + everything added so far. Total input is the sum over all calls, so it grows faster than the window.

Where does it go?

InformationPlace
Rules, tool descriptions (short, always needed)Context
Fast-changing facts (calendar)Tool result, this session only
Large existing documents (manuals)Retrieval via a search tool
Small lasting facts about a userNotes between sessions

When the context fills

Compaction; clearing old tool results; sub-agents with clean windows. Pair compaction with notes so key facts survive.
